# 基于 FPGA 的实时图像边缘检测与识别系统

项目基于易灵思 Ti60F225 开发板，实现摄像头采集、图像缓存、边缘检测和 HDMI 显示，并提供冻结、历史帧回放、延时对比及轻量 CNN 图案识别。代码和材料来自竞赛提交版本。

## 主要功能

- MIPI CSI-2 摄像头采集，DDR3 帧缓存，HDMI 显示；显示时序配置为 1920×1080、60 Hz。
- 图像预处理、灰度转换、Sobel 和流式 Canny 边缘检测；支持分屏、彩色画面边缘叠加和阈值调节。
- 冻结快照、最近 60 帧回放和左右延时对比。
- 32×32 灰度输入、965 参数、INT8 量化的轻量 CNN，对四类指定图案进行分类并叠加结果。该功能不是通用表情识别系统。

## 硬件与开发环境

- FPGA：Ti60F225 开发板；MIPI 摄像头、板载 DDR3、HDMI 显示器及按键。
- FPGA 开发工具：Efinity；工程文件标注版本为 2026.1.132。
- 工程包含 RTL、仿真测试和 Python 模型训练与导出脚本。具体依赖及原始测试脚本见工程内说明；脚本可能依赖原开发机器的工具路径，需要按本机环境调整。

## 版本与验证范围

提交技术文档描述了 3×3 处理和 13 拍流式 Canny 方案；工程的 `README_STREAM_CANNY.md` 指出后续存在 5×5 滤波修改，`active_programming_record.json` 记录的烧录文件又指向 `delivery_filter5_cleanup/`。这些文件反映不同版本，不能直接将技术文档中的延迟、资源与时序数据套用到所有构建或烧录文件。具体顶层参数、输出文件和上板状态应结合对应版本记录核对。

技术文档记录了模块测试、部分视频对照和布局布线结果；60 帧 DDR 全流程用例使用缩小帧长模型，而非完整 1080p 全量仿真。此处为原资料记录，尚未在本次整理过程中重新验证。
