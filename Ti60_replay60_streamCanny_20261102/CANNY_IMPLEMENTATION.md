# 传统 Canny 接入说明

当前版本另在原始彩色模式接入固定塔菲照片识别，操作与实现详见 [PHOTO_RECOGNITION.md](PHOTO_RECOGNITION.md)。该分支使用 64×64 灰度差模板，新增参考 ROM；本文件下文保留的 242 块 RAM、十五项仿真等数字属于接入照片识别前的 Canny/叠加/回看版本，最新构建结果以 outflow_canny/canny_verification.json 为准。当前回归共十七项。

本工程按用户选择采用完整滞后连接，Canny 实际处理分辨率至少为赛题要求的 640×480，允许降低边缘图更新率。摄像头、DDR 采集/回放、HDMI 视频时序沿用现有链路。

## 默认工作方式

- 开发板顶层 `u_camera_sobel` 设置 `CANNY_ENABLE=1`、`SNAPSHOT_ENABLE=1`；通用视频模块的参数默认仍为 0，以保留原 Sobel 回归与编译对照。
- 输入/输出视频维持 1920×1080，Canny 实际处理 640×480（307200 像素）。完整源画面按有理比例映射：横向 1/3，纵向 4/9，不裁剪视野。横向每三列采样一次，纵向每九行取第 0、3、5、7 行；显示按同一坐标映射读取完整结果。下采样为点采样，细小纹理可能混叠，当前没有前置抗混叠缩放器。
- 默认左半屏为原始灰度，右半屏为最新计算完成的 Canny 边缘；短按 SW3 循环切换分屏、实时彩图红色边缘、快照红色叠加、两帧回看。模式 1 在彩图上叠加最新完成的 Canny 图，不增加输出延迟；运动时边缘可能滞后，首次结果完成前显示彩图。左右半屏是同一画面各自的对应区域，未将两幅完整图像缩放并排。
- HDMI 保持原视频刷新节奏，Canny 连接计算期间重复显示上一份完整边缘图。首次计算完成前边缘区域为黑色。边缘图可能落后于实时灰度图。
- 开发板顶层设置 `CANNY_MEDIAN_ENABLE=1`，在下采样之前启用原 3×3 中值滤波，并补偿其中心像素偏移；下采样后仍进行高斯前处理。通用视频模块的参数默认仍为 0，两种配置都有视频对照测试。原 Sobel 路径保留。

## 算法

1. 高斯：3×3 核 `[[1,2,1],[2,4,2],[1,2,1]] / 16`，加 8 后右移，进行整数四舍五入。
2. 梯度：标准 3×3 Sobel，带符号计算 Gx、Gy。保存 `Gx²+Gy²`，避免开方和 8 位幅值截断；非极大值抑制及阈值比较与欧氏幅值的排序等价。
3. 方向：0°、45°、90°、135°，使用 `106/256` 近似 `tan(22.5°)`，不需要反三角函数。
4. 非极大值抑制：按图像坐标（y 向下）比较正确方向的两邻居。前邻居使用严格大于、后邻居使用大于等于，以确定性地处理平台并减少双像素线。
5. 双阈值：高阈值使用原按键寄存器，低阈值为其一半；阈值先平方再与梯度平方幅值比较。非零且通过 NMS 的点分类为强/弱边缘。
6. 滞后连接：保存整帧分类图，按 8 邻域反复扫描；只有与已确认强边缘相邻的弱边缘才晋升为强边缘，直到完整一轮无晋升才结束。与任意强边缘通过任意长度弱链连接的点都会保留，孤立弱连通域全部丢弃。这不是单次局部连接近似。

三个 3×3 窗口形成的三像素坐标偏移在写帧图时补偿；处理域四周各三像素置零。算法前端固定十拍，输入比例映射另有一拍，输出像素使能和坐标同步延迟。显示读图拆为坐标映射、帧地址计算、RAM 读取三拍，再补六拍，与原 HDMI/RGB/灰度九拍输出对齐；避免比例除法和 RAM 地址译码挤在同一时钟路径。

## 缓存与调度

片上缓存重构为 3 bit/像素：1 bit 候选掩码，加两份各 1 bit 的确认边缘图。前台确认图用于显示，后台确认图同时承担强边缘种子和连接计算，不再额外复制一份显示图。640×480 的帧图数据量共 921600 bit，另有行缓存和地址控制；比原先 4 bit/像素结构节省 25%。实际块 RAM 数量由映射方式和粒度决定，以综合报告为准。

状态顺序：等待完整帧起始 → 采集候选掩码与后台强边缘种子 → 多次连接扫描并直接更新后台确认图 → 等待显示场同步 → 原子交换前后台图。采集坐标不连续时丢弃不完整输入，下一帧重新采集。计算时不接收新分类帧，不阻塞摄像头、DDR 或 HDMI。

每个分类点扫描需要两拍；每个尚未连接的弱点最多再检查八个邻居（每邻居两拍）。连接迭代次数依图像而变，没有固定更新 FPS 保证，也没有以截断迭代牺牲连接完整性。640×480、148.5 MHz 下，单轮扫描约 4.14～37.24 ms；此外还有采集和等待场同步的时间。这是状态机周期估算，不是上板实测。HDMI 显示刷新率和 Canny 新结果更新率必须分别描述。

SW1/SW2 仍以步长 8 调节高阈值，范围 16～2032，默认 32；低阈值默认 16。新阈值在场同步提交，影响后续被接受的完整采集帧。已在计算中的旧帧会先完成，因此画面变化存在延迟。Sobel 欧氏幅值理论上不超过约 1443，超过该范围的高阈值会使强边缘消失。

模式 0/1 的 SW3 长按仍为手动冻结/恢复；模式 2/3 的长按是刷新快照/回看帧。模式 3 中 SW1/SW2 用于上一帧/下一帧，不修改阈值。详细操作见 `按键使用说明.md`。

## 红色叠加与两帧回看（节省内存）

未新建 RGB 帧缓存，也未增加整帧 DDR 存储区域。模式 2 复用现有 DDR 单帧锁定；模式 3 保存现有三帧缓存中的两帧，第三帧继续接收摄像头。保留的是原有 RAW 数据，显示仍经过原 ISP/RGB 链路。完成图的边缘像素替换为 `RGB=255,0,0`，其他 RGB 像素透传；输出保持九拍同步。

`canny_snapshot_control.v` 负责进入模式、刷新、读帧确认和旧数据排空。锁定确认后等待四个显示帧边界，回看还要求实际选择与请求一致，再清空旧边缘有效标记并开始新计算。计算完成前只显示原彩图，换帧时隐藏旧红线。该保护针对既有有限 FIFO/行缓存管线；仿真覆盖三帧预取延迟，上板仍需检查摄像头/DDR/ISP 的完整行为。

`frame_write_commit.v` 用 AXI AW/B 事务序号和四条元数据记录确认整帧写响应完成，避免将原有提前准备地址的 `wr_sw` 当作帧写完。序号按模 2^32 比较，队列溢出会禁止回看就绪。队列强制用寄存器实现，不占图像 BRAM。`bank_switch.v` 仅在两帧均完整且不属于当前写槽时保留它们，按读帧边界应用选择；退出时先恢复原有 clean/dirty 所有权，再允许正常轮换。

两帧回看不保证相邻采样时刻，不是录像功能。红色叠加为同帧快照显示，不承诺连续 60 FPS 的叠加更新。

## 文件与验证

- `rtl/canny_window3x3.v`：同步行缓存与窗口。
- `rtl/canny_frontend.v`：高斯、Sobel、方向、NMS、双阈值分类。
- `rtl/canny_hysteresis.v`：完整连接、帧完整性保护、后台结果发布。
- `rtl/canny_video_map.v`：下采样、处理/显示坐标转换。
- `rtl/sc431_sobel_video.v`、`rtl/ti60f225_oob_top.v`：视频链路集成。
- `tests/run_canny_tests.py`：独立整数前端参考和 BFS 洪泛搜索参考；对照 RTL 结果。
- `run_tests.ps1`：原有七组回归加八次 Canny/回看测试，共十五项。
- `build_canny.ps1`：综合、外围接口、布局布线、检查最终时序、生成烧录文件；输出独立保存于 `outflow_canny/`，不会自动烧录。
- `tests/check_canny_build.py`：检查源文件/约束新鲜度、最终 setup/hold 裕量、资源容量及烧录文件校验值；验证记录保存于 `outflow_canny/canny_verification.json`。

前端测试覆盖 3456 个像素，包括常量、横/竖/双斜向边缘、随机图、渐变、过高阈值、跨帧变化和稀疏 DE。连接测试与 BFS 对照，包括反向长链、孤立弱域、对角连接、输入丢帧、完整图发布、复位清除。视频联合测试覆盖启用/关闭中值前级的两种配置，验证下采样、边缘位置补偿、放大显示、同步与 RGB/灰度对齐、彩色切换、实际按键提高/降低阈值及完整结果延迟更新。

新增 `tests/canny_resolution_tb.v`，以真实 1920×1080 源坐标输入，检查恰好接受 307200 个连续的 640×480 处理坐标，覆盖所有 1080 条源行的取舍，再逐点核对全部 307200 个完成后的边缘像素及放大映射。参考图按独立整数模型和 BFS 生成。

旧中值测试中的相邻字符串语法已改为单字符串；旧阈值视频测试现在只在中值及 Sobel 两级窗口都完整后的行比较恒定梯度，避免把中值边界透传过渡误当作恒定斜坡。

## 本地仿真器

Icarus 11 及运行库已便携安装于 `tools/iverilog-portable/`。依赖从 conda-forge 下载并按发布校验记录验证，来源与本地 SHA-256 保存在 `tools/iverilog-install.json`。Windows 防护保持开启；被防护拦截的第三方安装包未运行。

执行 `./run_tests.ps1` 或 `python tests/run_canny_tests.py`。脚本只为当前进程配置工具路径和项目临时目录，不修改系统 PATH。重装脚本为 `python tools/install_iverilog.py`，需要联网。

实际摄像头图像质量、复杂场景更新率、实体按键、断电启动和板上长时间运行仍需硬件验证。这里没有替代 DDR 控制器；已实现快照式红色叠加和两帧逐帧回看，尚未实现录像、并排多帧对比或形状识别。
