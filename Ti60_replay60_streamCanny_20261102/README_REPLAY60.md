# 六十帧冻帧回放版本

基于用户提供的 Ti60_CNN(1).rar 修改，原包和已烧录 Flash 均未改变。

## 行为
模式3锁定最近60个完整提交的DDR帧，从最早到最新播放一次后停住。SW1选择更早一帧，SW2选择更新一帧，60帧循环；手动切帧中断自动播放。长按SW3沿用原版的重新采集与回放流程。其余模式、CNN权重、摄像头与引脚约束保持原版。

60帧并不等于60秒，覆盖时间为60除以实际完整帧提交速率。沿用每帧约六个显示周期的慢放节奏，实际播放时间还包含DDR切换确认等待。

## 实现
保留原模块名与项目结构。历史集合长度参数化；选择和帧槽索引扩为6位；DDR帧槽64个（60个历史加4个保护槽）。保持原有提交后发布、读边界选帧、选择确认与预取排空逻辑。模式2在历史不足时不读取未初始化条目。

原控制器配置：1 rank、8 banks、14行地址位、10列地址位、16bit数据，总可寻址256MiB。原帧槽步长4147712字节；64槽保留265453568字节（253.15625MiB），剩余2981888字节。未缩减图像容量、未扩大片上帧缓存。该容量判断基于工程配置，未重新读取实体DDR芯片型号。

## 验证边界
六帧兼容回归通过。六十帧元数据测试覆盖321次采集与2400次选帧；自动播放测试覆盖60帧顺序、等待确认、手动中断和重新采集；实际DDR读写RTL使用缩小帧长模型核对全部60帧数据。该测试不等于1080p整帧全量仿真或开发板实测。
