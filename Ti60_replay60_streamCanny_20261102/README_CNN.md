# Ti60 五分类 CNN 中文表情字幕与六帧回放

本版本在上一版 DDR3 六帧回放完整工程上接入已经训练的五分类 CNN。模式 1 的字幕根据本次 CNN 推理结果显示，类别不再共用 CNN TARGET。

## 屏幕显示

| 模型类别 | 显示文字 |
| --- | --- |
| 0：其他或无效画面 | 无法确定 |
| 1：taffy 闭眼露齿大笑 | taffy-大笑 |
| 2：taffy 闭眼小微笑 | taffy-放松 |
| 3：taffy 哭泣 | taffy-哭哭 |
| 4：taffy 睁眼张嘴 | taffy-微笑 |

上电、等待首次结果、分数不足、前两类接近、图像动态范围不足、画面不完整和连续确认未完成时，也显示无法确定。模型接受同一类别连续三次，才显示该名称。切换到另一类时清除旧名称，重新累计；一次拒绝结果就清除已确认类别。

已确认时取景框为绿色，得到结果但未确认时为红色，尚未得到结果时为黄色。文字和边框只在模式 1 显示。显示结果只在视频帧边界更新，沿用九个时钟的同步延迟。

系统仍采用固定的 512×256 面部取景框，需要手动调整距离和位置，让两只眼睛与嘴部同时进入框内。它没有增加自动人脸定位，不能把整幅人物图任意放在画面某处就视为已经正确取景。红色边缘、取景框和字幕叠加在识别取样之后，不进入 CNN 输入。

## 低分与接近类别的判断

五个整数 logits 以 1/256 为浮点分数单位。硬件先确定最大和次大分数，再采用 Q16 指数查表计算保守的 softmax 下界。最大类别分数下界至少为 0.7，且前两类分数差下界至少为 0.2，才通过分数门限。类别 0 无论分数多高都不显示表情名称。

分数判断按多个时钟周期顺序执行，避免把五类比较、指数查表和求和全部放在同一个时钟周期内。查表将指数项向上取整，使分母偏大、最大类别分数下界偏小；对次大项也取保守值。该实现可能比浮点更容易输出无法确定。0.7 表示模型内部 softmax 分数门限，不表示真实识别正确率为 70%。没有使用分数最高就强行输出名称的方式。

输入先进行 16×8 像素面积平均，得到 32×32 灰度图，完成整数 min-max 归一化，再进入 CNN。小于 16 的输入灰度动态范围直接拒绝。

## 网络、资源与保留功能

新网络主干与原版相同：1→4→8→8 通道的三层卷积，前两层带池化，末端全局平均后进行 8→5 全连接。共 965 个参数，940 个 int8 权重与 25 个 int32 偏置。权重 ROM 深度仍为 1024 字节，激活缓存仍为两块 1024 字节。最终整机 RAM、DSP 与时序以 outflow_cnn/cnn_verification.json 为准。

上一版完整工程保留在原目录。本版没有修改摄像头寄存器表、摄像头及开发板引脚约束、时钟约束、DDR 读写逻辑、Canny 算法、阈值控制或六帧槽位管理。新增逻辑使用独立模块和独立权重路径，旧二分类模块保留为历史回归入口；实际顶层启用 CNN_EXPRESSION_ENABLE=1，只实例化新 CNN 分支。

> 2026-10-31 更新：模式 2 已增加"左右延时对比"子状态（左半屏延时 N 帧、右半屏实时），
> 实现细节、资源时序与验证范围见 **`README_DELAY_COMPARE.md`**。

| 按键 | 功能 |
| --- | --- |
| SW3 短按 | 模式 0→1→2→3→0 |
| 模式 0 | 原灰度及边缘显示 |
| 模式 1 | 彩色、边缘叠加、CNN 中文表情结果 |
| 模式 2（默认态） | 原单帧快照和同帧边缘 |
| 模式 2（对比态） | 左半屏延时 N 帧 / 右半屏实时，中间 4 像素白线 |
| 模式 3 | 最近六幅完整图像的冻结回放 |
| 模式 3，SW1 / SW2 | 更早 / 更新的一帧，循环切换 |
| 模式 2 对比态，SW1 / SW2 | 时差 −1 / +1 帧（0~5 帧，约 0~83 ms） |
| 模式 0、1，SW1 / SW2 | 阈值增加 / 减少 8 |
| SW3 长按约 1 秒 | 模式 0、1 冻结或恢复；模式 2 切换快照态与对比态；模式 3 刷新冻结内容 |
| SW0 | 原工程复位 |

模式 2 的两种状态互斥：进入模式 2 时总是冻结快照，长按 SW3 切到对比态，离开模式 2 即清除。

本次表情结果只在模式 1 运行。六帧模式继续显示原有回放画面，没有给每幅回放图新增独立的表情元数据。

## 验证与复现

新增六组测试涵盖：922 个低分、近分、相同分数及有符号边界判断；全部五条中文文字的 10,240 个字模像素；连续三次同类确认与立即拒绝；32 个真实模型输入的 65,536 个中间特征与全部 160 个最终分数；实际面积平均、归一化及异常帧处理；614,400 个视频输出像素、取景框、字幕和九时钟同步。

原有 20 组回归、3 组旧 CNN 回归及 5 组六帧短测试也重新运行。1920×1080 六帧逐像素 DDR 测试记录沿用上一版；相关 DDR 源码未变。原测试记录与本版新增日志都保存在 test_output。

训练来源、标签、原图裁剪和 160 轮训练报告保存在 cnn/expression_multiclass_20261031。本次只接入已有训练成果，没有重新选择训练模型，也没有用板上测试结果调整门限。
